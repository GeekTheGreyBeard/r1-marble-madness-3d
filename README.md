# Marble Madness 3D — Momentum Lab (R1 Creation)

This is the **next version of the existing 3D Creation**, an original isometric, canvas-rendered physics prototype for a 240×282 viewport. It is not the separate 2D game. Its single floating test course is built to tune acceleration, coasting, counter-steering, climb/descent, collision, open-edge falling, checkpoint respawn and stable camera follow before level production. The seven data-defined sculptural sections include a narrow downhill bridge and lateral turn; there is no invisible outer wall or jump button. The 90-second clock, four-second fall penalty and finish feedback give a racing loop. The rendering is lightweight projected 2.5D geometry, **not WebGL or full rigid-body 3D**; the sphere uses a planar force/slope model with visual rolling, not full rotational contact dynamics.

## Controls

Tap **ROLL THE LAB**. The ball remains still at neutral spawn. Visible arrows steer in their on-screen directions; tilt auto-centers to the posture held when enabled, and **CENTER** resets that neutral position. Tilt right maps screen-right and pitch down maps screen-down in the browser convention; physical R1 axis/polarity and sensor availability require on-device validation. Hold **BRAKE** (or Space) to stop; release steering to coast. The physical wheel may dispatch browser `wheel` events to change FORCE 1–5; tap or swipe the visible **FORCE** control if it does not. Tap ☰ to pause/help/restart. No jump in this physics test.

## Verification

`node physics-test.mjs`, `node controls-test.mjs` and `node browser-test.mjs` (with a local static server on port 8765) check forces/slopes/collision/respawn, neutral stationary spawn, calibration/deadzone, projected four-way movement and braking. The 240×282 Chromium touch simulation covers real pointer touch steering, brake, fall/respawn, restart/reload, orientation-event injection and layout. Browser simulation is not R1 hardware validation. Retest on physical R1: neutral start without rolling, each arrow direction, enable tilt in intended holding posture then tip right/left/forward/back; if reversed, report exact axis and direction. Try CENTER while holding level, BRAKE to stop, wheel FORCE and visible fallback, edge fall/respawn, and reload. No further courses until physical feel is confirmed.

Deferred from the 744-line brief: production levels, moving hazards, bombs, surface variants, shortcuts, collectibles, score, audio/music, enemy marbles, sophisticated banking and 3D rigid-body/WebGL rendering. These are deliberately not substitutes for the physics feel gate. The original 2D game is unchanged. All visuals and code in this release are original procedural assets.
